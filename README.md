## 插件列表

| 插件名称 | 插件描述 |
|---------|---------|
| Omni Toolbox | 提供物品价格查询、收录管理、悬浮窗增强、快捷传送和多种自动化功能，让信息查询与日常操作更加方便。（仅支持在线安装） |
| Macro Redirection | 重定向技能施法目标，鼠标指哪打哪！（仅支持在线安装） |
| FF Logs Viewer (汉化) | 在游戏内查看 FF Logs 排名百分比，支持右键搜索（仅支持在线安装） |
| Distance (汉化) | 在游戏内显示到目标/单位的距离，并可显示支持 Boss 的仇恨范围，支持姓名板与多种自定义显示（仅支持在线安装） |
