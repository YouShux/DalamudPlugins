## 插件列表

| 插件名称 | 插件描述 |
|---------|---------|
| Omni Toolbox | 物品价格查询、库存查询、商店兑换位置、传送、解锁预览图片等功能。（仅支持在线安装） |
| Macro Redirection | 重定向技能施法目标，鼠标指哪打哪！（仅支持在线安装） |
| StarlightBreaker (汉化) | 解除国服屏蔽词限制，保持原生交流（仅支持在线安装） |
| FF Logs Viewer (汉化) | 在游戏内查看 FF Logs 排名百分比，支持右键搜索（仅支持在线安装） |
| BigPlayerDebuffs (汉化) | 在目标状态栏放大由你施加的增益/减益图标，便于观察（仅支持在线安装） |
| Enemy List Debuffs (汉化) | 在仇恨列表显示你的DOT剩余时间，便于多目标场景追踪DOT（仅支持在线安装） |
| Tilted (汉化) | 根据条件自动调整第三人称镜头角度与距离，支持战斗、副本、拔刀、骑乘、飞行、镜头靠近等模式（仅支持在线安装） |
| Distance (汉化) | 在游戏内显示到目标/单位的距离，并可显示支持 Boss 的仇恨范围，支持姓名板与多种自定义显示（仅支持在线安装） |
| Item Vendor Location (汉化) | 查找物品的商店售卖位置，右键菜单显示所有可能商店与坐标，支持聊天命令快速查询（仅支持在线安装） |
| Mouseover Action (汉化) | 鼠标指哪打哪（仅支持在线安装） |
| EngageTimer (汉化) | 完整倒计时 / 开怪计时 / OBS 叠加（仅支持在线安装） |
| Flash On Tell (汉化) | 收到悄悄话时让 FFXIV 窗口在任务栏闪烁（仅支持在线安装） |
| Waymark Preset Plugin (汉化) | 保存、编辑、放置、导入、导出与预览无限数量的场标预设，支持与游戏原生场标窗口联动与分类管理（仅支持在线安装） |
